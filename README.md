# 🏆 CodeChamp

## Aprenda Programação com Desafios

O **CodeChamp** é uma plataforma educacional desenvolvida para tornar o aprendizado de programação mais **prático, interativo e divertido**.

A plataforma reúne **aulas, quizzes, desafios e jogos**, permitindo que os usuários aprendam conceitos de programação enquanto colocam seus conhecimentos em prática.

O projeto foi desenvolvido com foco em estudantes que desejam aprender programação de uma forma mais dinâmica, utilizando diferentes linguagens e conceitos.

---

## 📌 Sobre o Projeto

O CodeChamp surgiu com a ideia de transformar o estudo de programação em uma experiência mais interativa.

Em vez de utilizar apenas conteúdos teóricos, a plataforma combina:

* 📚 Aulas
* 🧠 Quizzes
* 💻 Desafios de programação
* 🎮 Jogos
* 👤 Perfil do usuário
* 📊 Progresso de aprendizagem
* 🎥 Videoaulas
* 🔐 Sistema de login e cadastro

A plataforma permite que o estudante avance nos conteúdos e pratique seus conhecimentos através de diferentes atividades.

---

# 🎯 Objetivo

O principal objetivo do CodeChamp é **facilitar o aprendizado de programação**, oferecendo um ambiente onde o estudante possa aprender, praticar e testar seus conhecimentos.

O projeto também busca tornar o processo de aprendizagem mais interessante através da utilização de elementos de gamificação.

# 🎮 Modos de Jogo

Um dos principais diferenciais do CodeChamp é a utilização de jogos para tornar o aprendizado mais divertido.

## ⚔️ Batalha 1×1

Modo competitivo em que dois jogadores podem disputar uma batalha respondendo desafios relacionados à programação.

O objetivo é testar os conhecimentos enquanto compete contra outro jogador.

---

## 💣 Code Bomb

O **Code Bomb** é um modo baseado em tempo.

O jogador precisa resolver os desafios antes que o tempo termine.

Erros podem fazer com que o tempo disponível seja reduzido, aumentando a dificuldade da partida.

### Características

* ⏱️ Contagem regressiva
* 💻 Desafios de programação
* ❌ Penalização por erros
* 🏆 Competição por desempenho

---

## 🧠 Quiz Dev

O **Quiz Dev** é um modo de perguntas e respostas sobre programação.

As perguntas podem abordar diferentes tecnologias e conceitos, como:

* JavaScript
* Python
* HTML
* CSS
* SQL

Cada pergunta possui diferentes alternativas e apenas uma resposta correta.

# ⚙️ Como Executar o Projeto

## 1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd CodeChamp
```

---

## 2. Instalar as dependências

Entre na pasta do backend:

```bash
cd backend
```

Instale as dependências:

```bash
npm install
```

---

## 3. Configurar o banco de dados

O projeto utiliza MySQL.

Crie um banco de dados chamado:

```text
CodeChamp
```

Depois configure as informações de conexão no arquivo:

```text
.env
```

Exemplo:

```env
DATABASE_URL="mysql://usuario:senha@localhost:3306/CodeChamp"
```

---

## 4. Configurar o Prisma

Depois de configurar o banco de dados, utilize os comandos do Prisma necessários para gerar o cliente e sincronizar o banco conforme a configuração do projeto.

```bash
npx prisma generate
```

---

## 5. Iniciar o Backend

Execute:

```bash
npm run dev
```

O servidor será iniciado na porta:

```text
http://localhost:3000
```

---

## 6. Abrir o Frontend

Depois de iniciar o backend, abra o frontend utilizando um servidor local, como o **Live Server**, ou outro servidor HTTP.

---

# 🔗 Comunicação Frontend + Backend

O frontend se comunica com o backend através da API.

Exemplo:

```javascript
const API_URL = "http://localhost:3000";
```

Dessa forma, páginas como aulas, perfil e outras funcionalidades conseguem buscar e enviar informações para o servidor.
